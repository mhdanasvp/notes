# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Repository Purpose

This is a personal technical notes and study repository. It contains markdown notes, JavaScript/TypeScript practice files, and a Jupyter notebook covering various software engineering topics.

## Structure

Notes are organized into topic directories:

- `algorithms/` — algorithm concepts and practice problems (`problems.js`)
- `data structure/` — data structure notes and TypeScript examples (`examples.ts`)
- `leetcode/` — LeetCode problem solutions (`problems.js`)
- `problem-patterns/` — common coding problem patterns (`index.js`)
- `javascript/` — JS concepts (arrays, closures, memoization, function types)
- `node js/` — Node.js internals (event loop, V8, streams, child processes)
- `LLD/` — Low-Level Design: OOP, SOLID, UML, design patterns
- `system design/scalability/` — system design concepts with diagrams
- `mongodb/` — MongoDB load and data growth analysis
- `react/`, `next/` — React and Next.js notes
- `docker/` — Docker notes
- `ai-ml/` — ML, LLM, and PyTorch notes
- `ai-tools/claude/` — Claude CLI usage notes
- `markdown/` — Markdown cheatsheet
- `es-lint/`, `loadtest/` — tooling notes
- `train_llm_from_scratch (1).ipynb` — Jupyter notebook for LLM training from scratch

## Conventions

- Each topic lives in its own directory. New topics get their own directory.
- Markdown files (`.md`) are the primary format for concept notes.
- JavaScript/TypeScript files in `algorithms/`, `leetcode/`, and `problem-patterns/` are scratch files for working through problems — no module system, just plain functions.
- Assets (images, diagrams) go in an `assets/` subdirectory within the relevant topic folder.
